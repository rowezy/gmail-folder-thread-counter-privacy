# Gmail Folder Thread Counter — Privacy Policy

**Last updated: November 18, 2026**

## Overview

Gmail Folder Thread Counter is a Chrome extension that displays the total number of conversations associated with Gmail labels, rather than only unread message counts.

## Information We Access

The extension uses Google's Gmail API to retrieve:

- The connected Gmail account's email address.
- Gmail label names and identifiers.
- The total number of conversations associated with each label.

The extension requests Gmail metadata authorization. Although this permission can provide access to additional email metadata, the extension does not intentionally retrieve email message contents, subjects, or individual message headers.

## How Information Is Used

The information is used exclusively to display conversation counts in the Gmail sidebar.

The extension periodically refreshes these counts to reflect changes to Gmail labels.

## Data Storage and Sharing

The extension stores the connected account's email address, label names, conversation counts, and update status locally using Chrome's extension storage.

The extension communicates directly with Google's Gmail API. It does not transmit Gmail information to an independent application server.

We do not sell Gmail data, use it for advertising, or share it with third parties for marketing purposes.

## Data Retention

Locally stored information remains in the extension's Chrome storage until it is cleared or the extension is uninstalled.

## Security

Google OAuth is used to authorize access to Gmail. The extension does not collect or store Gmail passwords.

## Google API Services User Data Policy

Gmail Folder Thread Counter's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Changes to This Policy

This policy may be updated if the extension's functionality or data practices change.

## Contact

For privacy questions, contact the developer through the contact information provided on the extension's Google OAuth consent screen.
